Variable Rules

  • Variable names are case sensitive. "a" & "A" are different.
  • Only letters, digits, underscore (_) and $ are allowed (space not allowed).
  • Only a letter, underscore (_) or $ should be the first character.
  • Reserved words cannot be variable names.

Variable Rules

let, const & var

  • var : Variable can be re-declared & updated. It is a global scope variable.
  • let : Variable cannot be re-declared but can be updated. It is a block scope variable.
  • const : Variable cannot be re-declared or updated. It is a block scope variable.
